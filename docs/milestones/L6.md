## 0. The plan in one page

1. **Band C is reading and writing for meaning.** English moves through the rest of the letters, digraphs, clusters, long vowels and patterns, then sentences and short decodable texts. Hebrew reads every vowel sign, the soft letters, shva and hatafs, long words, prefixes, sentences and short texts, learns conventional spelling and script letters, and opens the unpointed bridge as an extension (D26). Russian learns groups 5 to 10, the syllable tables, words, sentences and texts, writes dictated words and sentences, and meets the grade-1 spelling rules.
2. **Templates:** **LS07** build a sentence; **LS08** `read_first` and `read_along`; two small modes the syllabi call for (**LS05 `table`**, the syllable table, and **LS01 `stem_first`**, "the word stays until tapped"); data-only extensions (capital and script stroke sets, script letter faces drawn from the stroke paths, `add_e` and final-form checks in LS06); validator rules for unpointed and helping-nikud text. **LS14** (the writing tray) stays later (Q-C1).
3. **Content:** about 380 English items, 400 Hebrew (with the unpointed extension) and 450 Russian (targets), in three sub-batches each, with 6 to 10 short texts per course written by the teachers and made final by the editor (Hebrew).
4. **Voices come later** (L5 §7). `read_along` needs word timing, which only a voiced clip can give; until then a page plays without lighting and every word can be tapped (§5.2).
5. **Do first** (marked **First**): LS07 and `read_first`, and the teachers' decodable texts, which are the slowest content to write and review.

## 1. Goal and "done when"

A child with Band C content open can build a sentence from word cards in the course's direction and hear it; read a short decodable text alone, tap a word for help after trying, and answer questions about it; reread a familiar text along with the voice; spell taught words with tiles and by hand; write capitals (English), script letters (Hebrew) and dictated words and sentences (Russian); and, in Hebrew, read the first unpointed words. Every item of the three Band C batches can be authored, validated and played with every clip pending.

"Done" means every criterion of §8 reported, each template verified once by the qa-engineer, the security items of §9 reviewed, each sub-batch validated and played once.

## 5. The template specs (in brief)

The rules of L5 §5 apply to all (the tap path, the three-step ladder with level 2 changing the representation, no timer, every distractor tagged, the course's direction and font, ids and numbers only in a response).

### 5.1 LS07 build a sentence: `build_sentence` 1.0 (**First**)

- **What the child does.** Puts word cards (each heard on a tap) into a line in the course's direction, to match a picture or a heard sentence. Options per item: capital and punctuation tiles (eng, rus); an **agreement choice** on a card (rus кра́сный / кра́сная; heb gender and number); a distractor card.
- **Modes:** `order` (scored against the listed orders); `free` (heb C-24: a sentence of the child's own; only the form is scored, see Q-C3).
- **Schema shape:**
  ```
  { "type": "build_sentence", "templateVersion": "1.0", "mode": "order | free",
    "scene": { "sprite": "…", "clip": "vo:…" },                     // the picture or the heard sentence
    "cards": [ { "text": "I", "clip": "vo:…",
                 "choices": [ { "text": "…", "clip": "vo:…", "tag": "…" } ] } ],   // agreement choices
    "marks": [ ".", "?" ],                                          // eng, rus, heb (. ? !)
    "answer": { "orders": [[0,1,2,3,"."]],                          // every correct order, listed
                "tagged": [ { "order": [0,2,1,3,"."], "tag": "eng.lis.adj_order" } ],
                "extraTags": { "4": "eng.spk.copula" } } }
  ```
- **Classifiers** (from the author's list only): adjective after the noun (`M-ENG-ADJ-ORDER`), no "is" (`M-ENG-COPULA`), no full stop (`M-ENG-PUNCT`), lowercase start (`M-ENG-CASE`), statement order in a question (`M-ENG-WORDORDER-Q`), agreement (`M-HEB-AGREE`, `M-RUS-GENDER`), case (`M-RUS-ACC`), number + noun (`M-RUS-NUMNOUN`). An order nobody listed is a retry with no tag.
- **Response code:** card indexes and mark ids in line order (`2.0.1.3.p`); `free` writes `built` or nothing.
- **Hint ladder:** level 1 the sentence heard again slowly, the first slot glowing (never lighting the cards in order, which would give the answer); level 2 a new representation: the picture with its parts numbered in the order they are said (eng ADJ-ORDER: big, red, ball colour-coded; rus and heb: the agreeing card and the noun lit in the same colour); level 3 the friend builds the sentence, the line clears, the child builds it.
- **Validator:** every listed order uses every needed card once; at least two tagged wrong orders or tagged extra cards; agreement choices tagged; the course's direction; spaces between cards are drawn, never typed; `free` items have no `orders` and no content in the response.

### 5.2 LS08 `read_first` (**First**) and `read_along`

- **`read_first`.** The child reads a page alone (the text shown in the course's font, pointed Hebrew, Russian stress per V-5). A word becomes tappable to hear it after a short settle on the page (the child has looked first; it is never timed against the child and never counted). Reading is **unscored practice** (D22). The questions after it are LS01 items, scored. A parent co-play card at the end. The validator runs V-3 on every page.
- **`read_along`.** The voice reads the page and each word lights as it is read (frame §2.3). The light needs **word timing per clip** (`timing`: one start time a word), which only a voiced clip can give: the voice-and-sound-director decides whether it comes from the vendor's timestamps or is marked by hand, at voicing time. **Until a page has timing**, it plays the page clip with no lighting and every word can be tapped, like `read_first`. With the language's voice on and the model released, the child may repeat a phrase (the say step, as `echo`); no evidence (E-1).
- **Schema shape:** `pages`: each `sprite`, `text` (`words: [{ text, clip? }]` or a `text` split by the builder), `clip` (the page), `timing` (optional, filled at voicing); `questions` (LS01 items by id); `card` (a co-play card id).
- **Hint ladder:** a `read_first` page has none (it is practice; a word tap is the help); the questions keep theirs.

### 5.3 LS05 `table`, the syllable table (Q-C2)

- **What the child does.** A grid: the taught consonants in rows, the vowel letters (rus, in their pairs а–я, о–ё, у–ю, ы–и, э–е) or vowel signs (heb) in columns. `explore` (unscored): tap a cell, hear its syllable. `find` (scored): hear a syllable, tap its cell.
- **Why a table and not 25 choices:** the child can reason by row and column, which is the point of слоговые таблицы in the Russian primer tradition (Goretsky; rus syllabus C-08) and of the Hebrew צירופים charts. The two-choice and three-choice rules still hold because the classifier treats the cells by their relation to the target, not as free choices.
- **Classifiers by position:** the pair partner in the same row (мя for ма) → `M-RUS-HARDSOFT`; the ы/и partner → `M-RUS-YI`; the same column, a look-alike letter in another row → `M-RUS-SHAPE` or `M-RUS-LATIN`; heb: the same letter, another sign → `M-HEB-VOWEL-SHAPE` or `-VOWEL-OU`; any other cell → a retry with no tag.
- **Hint ladder:** level 1 the syllable again and its row lights; level 2 the merge of LS04 for that row's consonant (a new representation: motion); level 3 the friend taps it.
- **Validator:** rows and columns only of taught letters or signs; every cell has a clip id; at most 6 rows by 6 columns on a phone (the design-director's layout may cut it).

### 5.4 Smaller pieces

- **LS01 `stem_first`** (eng C-11): the word or sentence stays on the stage until the child taps "I read it"; then the picture options come. Never a time limit (frame §2.2: `flash` is never for reading).
- **LS06 `add_e`** (eng C-08): the child adds or leaves out the final e to match the picture (cap / cape); classifier `M-ENG-E-SILENT`. **`finals: check`** (heb C-20): a non-final letter at the end is "not yet", tag `M-HEB-FINAL`.
- **Script faces** (heb C-25): an option face `form` (a stroke-set form id) is drawn from its `d` paths with the ink width, so the script letters need **no new font** (CLAUDE.md: Heebo and Secular One only). The design-director checks the drawn faces at tile size.
- **T18 `clock_set` in a language pack** (eng C-20): allowed with the two-clip prompt; its classifiers are the clock's own (core tags are refused in a course, so the clock items carry only English tags, `M-ENG-SEM` on a neighbour hour heard).
- **An online-safety moment** (frame §5.2, optional): one scripted puppet line in English and Russian Band C ("we don't tell an app where we live") and a parent card. The teachers decide; I recommend it (Q-C5).

## 8. Acceptance criteria (reported one by one at the end)

1. **LS07:** a listed order is right; a tagged wrong order or extra card gives its tag; an unlisted order is a retry with no tag; agreement choices work in Hebrew right to left and Russian left to right; `free` scores only the form and writes no content.
2. **LS08 `read_first`:** pages are unscored and write no attempt; a word tap plays its clip; the questions are scored; every page passes V-3; the Hebrew parent check shows only in the parent view and is no mastery evidence.
3. **LS08 `read_along`:** with timing, each word lights in time with its page clip (tested with fixture timing); without timing, the page plays and words can be tapped; the say step only with the language's switch on and the model released.
4. **LS05 `table`** (if built): `explore` writes nothing; `find` is classified by position as §5.3.
5. **The small pieces:** `stem_first` has no time limit; `add_e` and `finals: check` classify as §5.4; T18 plays in a language pack with only course tags; script faces are drawn from the stroke paths and pass the design-director's check at tile size.
6. **The validator rules V-1 to V-6** each have a test on a fixture pack that breaks them; the starter pack and the Band A and B packs still pass.
7. **Content:** every sub-batch validates, its script checks pass, every skill can reach fresh mastery in the simulator, every Hebrew line is `text-ready`, every target text is approved by its teacher, every text is decodable at its step, and a playthrough with every clip pending passes.
8. Analyzer clean, format clean, the whole Flutter suite green; PLAN.md updated.

## 9. Security and child-safety items (for the security-engineer's review)

1. **LS07 `free`** (heb C-24): the child's sentence lives only in the session; the response is `built` or empty; nothing is logged or synced (frame §1.5 invariant 9).
2. **The Hebrew parent check of reading aloud:** a parent-area event (an enum), behind the parent gate, synced like the other parent confirmations; no audio.
3. **`read_along` and `echo` speech:** as L5 §11 item 4. Reading aloud is never evidence.
4. **The own name with its capital** (eng C-13, LS06 `own_name`): as L5 §11 item 2.
5. **The online-safety moment** (if approved) asks nothing; it is a puppet's statement and a parent card.
6. **Timing data** is pack content (numbers, bounded by the clip length), signed with the pack.
7. No new package, no new host, no model change.

## 12. What I found inconsistent (in addition to L5 §14)

1. **Hebrew C-26** names the Ministry's groups, but the stroke data use the school's five groups and no Ministry arrow chart was found (Q-C4). → hebrew-language-teacher.
2. **Hebrew C-09** says "at a glance"; the row itself says the app never times a child, so "at a glance" means right first time in a mixed set. The parent text must not say "fast". → hebrew-text-editor when the parent texts are written.
3. **Russian C-22** allows "handwritten print or tiles"; frame §2.3 lists C-22 under LS02 only. Both are fine (tiles for a child whose hand is slow, the word canvas for writing), but the batch should give both and say which counts for which skill (tiles for spelling, the canvas for the writing facet, L6 E-2). → russian-language-teacher.
4. **English C-13** lets the child's own name be built "with its capital" through LS06 `own_name`, which in L5 is Hebrew-only; the English case needs the capital tile and a Latin name typed by the parent. A Hebrew-script name in the English course would have no Latin letters, so the fallback character name is used. → english-language-teacher, app-developer.
