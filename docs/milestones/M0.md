## 9. Risks and unknowns

- **Attestation parsing is the hardest code in M0.** App Attest (CBOR plus an X.509 chain with a nonce extension) and Key Attestation (an ASN.1 extension) are easy to get subtly wrong. Mitigation: fixtures from a test root, the Phase G hardware check, and both Google roots.
- **iOS cannot be debugged from here.** Every Swift change is a Codemagic build (500 free minutes a month) and a TestFlight install. I keep the Swift small, behind a Dart interface, and batch changes.
- **App Attest has two environments** (development and production). TestFlight builds use production. The server config lists the accepted one, so an environment mismatch shows up as a clear refusal, not a mystery.
- **Free Supabase tier** pauses on inactivity; `pg_cron` jobs catch up on resume. Acceptable for M0; revisit before the family relies on it.
- **Windows file paths and line endings.** `.gitattributes` forces LF; the repo path stays short.
